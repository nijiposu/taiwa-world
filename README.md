# 世界をめぐる対話の場（仮）

好きなものを持ち寄り、さまざまな世界を訪れながら対話する60分のための Web アプリ。
虹乃氏・ちえさんの共同開催イベント用。声は Zoom / Google Meet でつなぎ、この画面は世界観・お題・リアクションを担当します。

## 動かし方

```bash
cd taiwa-world
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に静的ファイルを出力
```

- `?room=xxxx` でルームを分けられます（省略時は `demo`）。
- 同じブラウザで別タブを開くと、別の参加者として入室でき、移動・お題・リアクションが同期します（Phase 2 の動作確認用）。

## いまできること

### 世界地図
メイプルストーリーの地図のように、島になったエリアに触れると詳しく見られ、ホストは「みんなで行く」で全員を連れて移動できます（ダブルクリックでも移動）。みんなの現在地と、今日訪れた場所に印がつきます。

| エリア | ワールド | 遊べること |
| --- | --- | --- |
| 樹のエリア | 樹の下の焚き火（集合場所） | 揺れる炎・火の粉・ほたる。背後にナゴリの樹。焚き火に触れると火が爆ぜ、夜空に触れると流れ星 |
| 樹のエリア | ナゴリの樹 | 幹に触れると問い、葉にことばを残せる。リアクションと言葉の数だけ樹に灯りがともる |
| 倭のエリア | 灯籠祭 −心の旅路− | 風鈴・おみくじでお題、灯籠にひとことを託して流す、夜空に触れると花火 |
| 月のエリア | （準備中） | ちえさんの作品が入る予定。地図では霧がかかっている |
| 水のエリア | 水底郵便局 | 入口の扉から受付へ。封筒を選ぶと次の問いが届く。配達員さんのひとこと、ことばを瓶に入れて預ける |
| BBQ広場 | 才能BBQ | 看板に今日のテーマ。「わかる！」などのリアクションで炭火が5つ灯る。案内どんぐりのひとこと |
| 町のエリア | やりたいことが消えた町 | 最初は灰色の町。時計塔に触れると次の問い、「好き」やリアクションが集まると町に色が戻る |

**世界観は対話の促進剤**：問いはどのワールドでも共通の山札から出し、作品のゲーム内容（BBQのカード、郵便局の仕分けなど）は持ちこまない。
気に入った人が作品で遊べるよう、`src/config/links.ts` に URL を書くと「作品で遊ぶ ↗」の入口が地図と各ワールドに出る。

### 全ワールド共通
| | |
| --- | --- |
| お題カード | 山札（重複なし）。ホストは一覧から選ぶ／その場で書くこともできる |
| リアクション | 🧡わかる！ ✨もっと聞きたい ✋私も話したい 🌱違う視点がある。ワールドごとに演出が変わる |
| 話したい順番 | ✋ は順番待ちに並び、ホスト画面で光る。「どうぞ」で解除 |
| 参加者 | ホスト2・ゲスト2。アイコン・オンライン状態・直近のリアクション |
| 今日の記録 | テーマ・訪れたワールド・話した問い・残したことばを自動で集め、作品／感じたこと／気づき／ホストのひとことを書ける。コピー・保存・印刷 |
| その他 | 60分タイマー、移動時の演出、BGM・効果音（オフが既定）、スマートフォン対応 |

ホストだけができること：ワールドの移動、山札を引く・問いを選ぶ、テーマ設定、順番待ちの解除、記録へのひとこと。
各ワールドのギミック（風鈴・おみくじ・樹・灯籠・葉・封筒・カード・時計塔・「好き」）とリアクションはゲストも使えます。

## 技術構成

- **Vite + React + TypeScript**：UI。依存は React のみ。
- **Canvas 2D**：各ワールドの動く演出（`src/worlds/*Scene.ts`）。外部ライブラリなし。重い背景はオフスクリーンに一度だけ描き、毎フレームは粒子だけを描く。タブが隠れている間は停止し、「視差効果を減らす」設定では粒子を減らす。
- **Web Audio**：効果音・環境音の合成（`src/audio/sound.ts`）。

### Phase 2 への拡張ポイント

状態は「Action → reducer」でだけ変わる作りにしてあります。

```
UI ──dispatch(Action)──▶ RoomStore ──reduce──▶ SessionState ──▶ 画面
                             │  ▲
                   transport │  │ 他の端末からの Action
                             ▼  │
                         RoomTransport（いまは BroadcastChannel）
```

- `src/state/types.ts` の `Action` が、そのまま通信で流すメッセージになります。乱数（引いたお題など）は送る側で確定させて Action に含めるので、全員の画面が同じになります。
- `src/state/transport.ts` の `RoomTransport` を Supabase Realtime / PartyKit / Liveblocks などで実装し、`RoomStore` に渡せばオンライン化できます。オンライン状態（presence）と途中参加時のスナップショット送信も、同じ interface の上に実装済みです。
- 演出は `useActionEffect` で Action を購読して起こすため、他の人のリアクションでも自分の画面で花火や火の粉が上がります。

おすすめは **Supabase Realtime**（Broadcast + Presence がそのまま対応し、招待制ルームや記録の保存を Postgres に置ける）。サーバーで状態を一元管理したくなったら PartyKit も相性がよいです。

## 作品素材について

水底郵便局・才能BBQ・やりたいことが消えた町の背景とBGMは、虹乃氏の Google Drive の作品素材を縮小して使っています。
**このリポジトリは公開なので、素材ファイル（画像・音源）は git に入れていません**（`.gitignore` で除外）。
`public/assets/` に置けば表示され、置いていない場合は色のグラデーションと合成音で代わりに動きます。

| 置く場所 | 元の素材 |
| --- | --- |
| `minasoko/entrance.webp` `counter.webp` `ambient.mp3` | 水底郵便局「入り口に入る」「受付カウンター」「02 郵便局入り口 海の底の灯り」 |
| `bbq/plaza.webp` `guide.webp` `card-person.webp` `ambient.mp3` | 才能BBQ「シーン②」・案内どんぐり・人物カード・「メインワーク中」 |
| `town/plaza.webp` `clocktower.webp` `scrapyard.webp` `ambient.mp3` | やりたいことが消えた町「オープニング」「時計塔」「夢のスクラップ置き場」「01.やりたいことが消えた町」 |
| `atlas/*.webp` | 各作品のタイトル画像（地図の詳細カードに表示） |

## 差し替え・編集の場所

| 変えたいもの | ファイル |
| --- | --- |
| 背景イラスト・前景・環境音・ロゴ | `public/assets/<world>/` に置き、`src/config/assets.ts` にパスを書く |
| お題カード | `src/data/topics.ts` |
| 案内役のセリフ | `src/data/worldTopics.ts` |
| 作品への入口（URL） | `src/config/links.ts` |
| 世界地図のエリア（位置・色・準備中） | `src/data/atlas.ts` |
| ワールド名・説明文・色 | `src/data/worlds.ts` |
| リアクションの種類 | `src/data/reactions.ts` |
| 席（ホスト名・既定アイコン） | `src/data/seats.ts` |
| アプリ名・時間 | `src/config/app.ts` |

## ディレクトリ

```
src/
  state/    状態・Action・reducer・同期（Phase 2 の差し替え口）
  engine/   キャンバス演出の土台
  worlds/   各ワールド（*Scene.ts が演出、*World.tsx がギミックとUI。ImageWorld は作品イラストを舞台にする共通部分）
  ui/       お題カード・リアクション・参加者・記録などの共通UI
  audio/    効果音・環境音
  data/     お題・ワールド・席などの編集しやすいデータ
  config/   素材とアプリ設定
```
