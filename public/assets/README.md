# 差し替え素材の置き場所

ワールドごとのフォルダに画像・音源を置き、`src/config/assets.ts` にパスを書くと反映されます。

| フォルダ | ワールド |
| --- | --- |
| `campfire/` | 焚き火の広場 |
| `lantern/` | 灯籠祭 −心の旅路− |
| `nagori/` | ナゴリの樹 |

- `background`：背景イラスト（16:9 以上・横 2400px 程度の JPG/WebP 推奨）。指定すると、コードで描いた背景のかわりに敷かれます。炎・花火・光の粒などの動く演出は、その上に重なります。
- `foreground`：前景イラスト（透過 PNG/WebP）。演出の上に重なります。
- `ambient`：環境音（ループする MP3/OGG）。
- `logo`：移動時に表示するワールドのロゴ（透過 PNG/SVG）。
